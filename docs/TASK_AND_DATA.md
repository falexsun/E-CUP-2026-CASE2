# Задача и данные

## Постановка

Для каждой карточки товара по названию, описанию и 1–5 изображениям требуется:

1. определить соответствие правилам указанной категории;
2. сформировать объяснение для сотрудника модерации;
3. вернуть строгий бинарный вердикт `бан` или `не бан`.

Официальная метрика — среднее положительного F1 по двум категориям:

```text
Macro F1 = (F1_positive(БАД) + F1_positive(Легковоспламеняющиеся)) / 2
```

## Схема `data.csv`

| Поле | Значение |
|---|---|
| `id` | идентификатор товара |
| `name` | название |
| `description` | описание |
| `category` | `БАД` или `Легковоспламеняющиеся` |
| `label` | `1` — соответствует правилам категории, `0` — не соответствует |

Released train содержит 12 971 строк. Изображения находятся в
`data/images/<id>/`.

## Правила категории «БАД»

Положительный класс требует прямого указания `БАД`, `биологически активная
добавка` или `dietary supplement` в описании либо на изображении.

К отрицательному классу относятся:

- спортивное питание, включая аминокислоты, BCAA, L-карнитин и протеин;
- карточки с явным указанием, что товар не является БАД;
- товары без обязательной маркировки БАД.

## Правила категории «Легковоспламеняющиеся»

Положительный класс:

- самостоятельный источник открытого огня — например, спички или зажигалка;
- товар с горючим веществом, легковоспламеняющимся содержимым или горючим газом;
- комплект, в который входит легковоспламеняющийся товар.

Отрицательный класс:

- конструкция для использования с огнём без горючего содержимого — например,
  пустой мангал, гриль или газовая плита;
- устройство, поставляемое без топлива или другого горючего содержимого;
- изделие со встроенным источником воспламенения;
- горючий материал только как несамостоятельный компонент изделия;
- карточка, где потенциально легковоспламеняющийся предмет не входит в комплект.

## Формат результата

CSV содержит ровно две колонки `id,result`. Поле `result` имеет вид:

```text
<комментарий>объяснение длиной от 50 до 300 символов<вердикт>бан
```

или заканчивается на `<вердикт>не бан`. Закрывающие XML-теги не используются.

## Ограничения runtime

- изолированная среда без интернета;
- модели до 4B с открытой лицензией;
- официальный образ `odsai/ecup26-quality-baseline:1.0`;
- public/private наборы содержат новые товары;
- базовые Qwen-модели доступны через `SHARED_MODELS_PATH`.

Источники: [страница данных соревнования](https://ods.ai/competitions/e-cup-2026-quality/dataset)
и [официальные правила E-CUP 2026](https://storage.yandexcloud.net/ds-ods/files/data/docs/competitions/E-CUP-2026/E-CUP-2026-Rules.pdf).
